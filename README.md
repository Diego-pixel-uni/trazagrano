# TrazaGrano

Mural digital de la actividad de la semana 2 de Gerencia de Proyectos de Software.

Formula una app para que cada lote de café se pueda rastrear hasta su parcela: contexto, objetivos, alcance, recursos, riesgos, diagrama de Gantt, presupuesto y conclusiones.

- `index.html`: el mural.
- `presupuesto.py`: el cálculo del costo por fase y por rubro. Se ejecuta con `python presupuesto.py`.
